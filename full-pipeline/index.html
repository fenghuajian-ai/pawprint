跨境电商 AI 全流程自动化管线

输入品类 → 4 阶段自动运行 → 输出可交付成果

选品扫描 → 竞品拆解 → Listing 生成+审核 → 监控部署

一键运行

python auto_pipeline.py --product "蓝牙耳机" --market "US"

换成任意品类和站点即可复用：宠物饮水机、瑜伽裤、充电宝...
