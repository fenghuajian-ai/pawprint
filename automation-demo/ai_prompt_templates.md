# AI Prompt 模板库

> 以下 Prompt 模板经多次验证优化，可直接复用。
> 使用时替换 `[方括号]` 中的变量即可。

---

## 模板 1：竞品差评分析

```
你是跨境电商运营专家。分析以下 [品类] 在亚马逊 [站点] 的
Top [N] 竞品的一星/二星差评数据。

竞品列表：
[竞品名称、ASIN、链接]

请按以下维度分类所有差评：
1. 产品质量（材质、做工、耐用性）
2. 功能问题（是否与描述一致、性能表现）
3. 尺寸/适配（偏大偏小、不兼容）
4. 包装/物流（破损、延迟）
5. 客服体验（响应速度、解决方案）

输出格式：
- 每个维度标注出现频率（高/中/低）
- 列出最具代表性的 3 条差评原文摘要
- 提炼该品类的"致命痛点"（导致退货的最核心原因）
- 建议产品改进方向和 Listing 优化重点
```

## 模板 2：Listing 标题+五点生成

```
你是亚马逊 [站点] 的资深 Listing 优化师。
目标客群：[性别/年龄/使用场景]

产品信息：
- 品类：[蓝牙耳机/宠物用品/健身器材]
- 核心卖点：[3-5 个核心卖点]
- 竞品差评痛点：[从模板 1 中提取的致命痛点]
- 价格定位：[budget/中端/高端]

请生成 2 套 Listing 方案：

方案 A 瞄准性价比客群（标题侧重参数和功能数量）
方案 B 瞄准品质导向客群（标题侧重体验和差异化）

每套方案包含：
1. 标题（150-200 字符，植入 3 个核心关键词）
2. 五点描述（每条 200-250 字符，回答"对你有什么好处"）
3. 搜索关键词（后台 Search Terms）

每条卖点必须回应一个竞品差评痛点，不能堆砌参数。
标注任何可能违反 FTC 规范的表述并给出替换方案。
```

## 模板 3：客服回复模板生成

```
你是亚马逊 [站点] 的客服专家。
产品：[产品名称]
常见退货原因：[列出 Top 3 原因]

请为每种退货原因生成 3 套回复模板：

1. 售前提醒模板：在用户下单后自动发送，
   提前告知可能的问题并给出使用建议

2. 售后挽留模板：用户申请退货时发送，
   先共情再提供替代方案（补发配件/部分退款/替换）

3. 差评公开回复模板：对已发布的 1-2 星差评的公开回复，
   语气专业、不推卸责任、展示实际改进措施

注意：
- 遵守亚马逊的买家消息规范
- 不能诱导用户改评或删评
- 不能包含外部链接或联系方式
- 适应 [目标市场] 的文化沟通风格
```

## 模板 4：运营数据周报分析

```
你是跨境电商数据分析师。以下是本周运营数据：
[粘贴 Excel/CSV 数据或手动输入关键指标]

请分析：
1. 与上周对比，哪些指标有明显变化（>10%）？
2. 变化的原因可能是什么？
   （从流量来源、竞品动作、季节性、平台政策等角度分析）
3. 本周最值得关注的 3 个问题和 3 个机会
4. 下周建议的运营动作（按紧急程度排序）

要求：每个结论后面标注"数据来源"或"推测依据"，
不确定的地方明确说"需进一步验证"。
```

## 模板 5：AI 输出质量自检

```
请自我检查你刚才的输出：

1. 是否有任何未经核实的数据或引用？（标注出来）
2. 是否有逻辑前后矛盾的地方？（举例说明）
3. 是否有可能违反 [目标市场] 的文化规范或法律规定？
4. 是否有模糊、夸大的表述？（替换为具体可验证的描述）
5. 是否有遗漏的重要维度？（补充）

请逐条回答。
```

---

## 模板使用说明

1. **不要直接复制** — 根据实际品类和场景替换方括号内容
2. **每次用完记录效果** — 哪个 Prompt 效果好/差，写备注
3. **持续迭代** — 把好用的 Prompt 更新到这个模板库
4. **团队共享** — 新同事用同一个模板，输出质量就有一致性
