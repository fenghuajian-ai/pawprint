# 跨境电商 AI 工作流 SOP 手册

> 本文档沉淀了 AI 辅助跨境运营的标准化工作流程。
> 目标：将个人经验转化为团队可复用的模板，降低新人上手门槛。

---

## 工作流一：AI 竞品调研与选品分析

**触发条件：** 运营提出新品类调研需求，或每周例行竞品监控

**标准流程（SOP）：**

| 步骤 | 操作 | 工具 | 产出 |
|------|------|------|------|
| 1 | 确定品类和竞品范围（Top 5-10） | 人工判断 | 竞品 ASIN 列表 |
| 2 | 采集竞品基础数据（价格/评分/BSR排名） | Python脚本 + Keepa API | 数据表格 |
| 3 | 批量抓取一星/二星差评 | AI 辅助 + Playwright | 差评原始数据 |
| 4 | AI 分类差评，提炼痛点排行榜 | Claude/ChatGPT | 痛点分析表 |
| 5 | AI 生成竞品对比矩阵 + 机会分析 | Claude/ChatGPT | 竞品报告 |
| 6 | 人工校验数据准确性 + 标注信息来源 | 人工 | 终版报告 |

**时间估算：** 传统方式 6-8 小时 → AI 辅助 **30-45 分钟**

**Prompt 模板（步骤 4-5 可复用）：** 见 `ai_prompt_templates.md`

## 工作流二：AI Listing 优化

**触发条件：** 新品上架前，或旧品转化率低于类目均值

**标准流程（SOP）：**

| 步骤 | 操作 | 检查点 |
|------|------|--------|
| 1 | 输入竞品差评数据 + 目标客群画像 | 确保 AI 有足够上下文 |
| 2 | AI 生成 2-3 套标题+五点方案 | 要求针对不同客群 |
| 3 | 逐条核验：是否回应了真实差评痛点？ | 每一条卖点必须有差评数据支撑 |
| 4 | 检查关键词密度 + FTC 合规性 | 不能有虚假宣称（如"best in class"） |
| 5 | 人工终审 + A/B 测试计划 | 上线后 2 周看转化率对比 |

**质量标准 Checklist：**
- [ ] 标题包含核心关键词（品牌词+品类词+功能词）
- [ ] 每个 Bullet Point 回应了一个真实用户痛点
- [ ] 没有违反 FTC 广告规范的夸大宣称
- [ ] 没有触达目标市场的文化禁忌
- [ ] 拼写和语法经人工检查

## 工作流三：AI 客服话术优化

**触发条件：** 某 SKU 退货率突增，或收到批量同类差评

**标准流程（SOP）：**

| 步骤 | 操作 |
|------|------|
| 1 | 导出近期退货原因和差评原文 |
| 2 | AI 分类退货原因（质量/尺寸/描述不符/物流） |
| 3 | AI 根据每类原因生成 3 套回复模板：售前提醒 / 售后挽留 / 差评公开回复 |
| 4 | 人工校验话术是否符合品牌调性和平台规则 |
| 5 | 沉淀为客服 FAQ 文档，同步到飞书知识库 |

---

## 工作流四：自动化数据日报

**每日定时执行：** 上午 9:00

**流程：**
```
Python 脚本自动运行
  → 采集竞品数据（价格/排名/评分）
  → 对比昨日数据，标记异常（价格波动>10%、排名骤降）
  → AI 分析异动原因 + 生成运营建议
  → 推送到飞书群/钉钉群
```

**脚本文件：** `competitor_monitor.py`

**异常告警阈值：**
- 竞品降价 >15% → 立即告警
- 排名下降 >50 位 → 3 小时内复查
- 新增一星差评 >2 条 → 当天分析原因

## 如何将这套 SOP 复制给团队

1. **新人入职第一周：** 照 SOP 手动执行每一步，理解流程
2. **第二周：** 开始用 Prompt 模板辅助，减少手动时间
3. **第三周：** 能独立完成一个品类的全流程分析
4. **一个月后：** 沉淀自己的 Prompt 优化经验和 Case Study

每个运营做完一个品类后，**必须把自己优化的 Prompt 和遇到的坑更新到共享知识库**，否则个人经验无法变成团队资产。

## AI 输出质量核验框架

**每条 AI 输出必须通过以下检查：**

| 维度 | 检查内容 |
|------|---------|
| 事实准确性 | 引用的数据、价格、评分是否可溯源？ |
| 逻辑一致性 | 结论是否与数据矛盾？前后观点是否打架？ |
| 文化敏感性 | 是否可能冒犯目标市场的文化/宗教/种族？ |
| 合规性 | 是否违反 FTC/ GDPR / 平台广告规范？ |
| 完整性 | 是否遗漏了重要维度或关键竞品？ |

**一句话铁律：AI 的输出 = 初稿，不是终稿。不校验不发。**
